Y-Lab website — images folder
=============================

Put photos in this folder using the exact filenames below, then upload the
whole folder next to index.html. No code changes needed.

  your-server/
    index.html
    publications.bib
    images/         <- this folder

Use .jpg (preferred) or .png — those are the two the page looks for. Convert
.jpeg / .webp / .heic files to one of them first. A missing file just shows the
grey placeholder; nothing breaks.
Recommended: portraits ~600x800, figures ~1200px wide, under ~400 KB each.
